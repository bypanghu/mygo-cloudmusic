# 网易云音乐 · MyGo

用 Go 和 [MyGo](https://github.com/egoist/mygo) 写的第三方网易云音乐桌面客户端，原生界面，无 WebView。

## 功能

### 发现与搜索

- 每日推荐、推荐歌单、排行榜、我的歌单
- 私人 FM（推荐 / 熟悉 / 探索）与心动模式
- 分类搜索单曲、歌手、专辑、用户和播客，支持加载更多、刷新与失败重试
- 输入关键词时显示搜索建议，可直接打开歌手、专辑或歌单；支持方向键选择、Enter 确认、Escape 关闭
- 搜索历史保存在本机，支持再次搜索与一键清空；返回 / 前进可重新查看之前的搜索结果

### 歌手、专辑与用户

- 歌手详情：热门歌曲、专辑列表、歌手简介，以及关注 / 取消关注音乐人
- 歌手动态：查看公开文字、图片与分享的歌曲、专辑和歌单，支持刷新与加载更多；暂不支持应用内查看动态视频
- 专辑详情：封面、歌手、发行日期、简介与歌曲列表
- 用户主页：个人资料及其创建的公开歌单
- 点击歌曲列表、正在播放页中的歌手或专辑，或使用歌曲菜单，即可打开对应详情，不打断当前播放

### 播客

- 搜索播客、查看播客与主播资料，分页浏览节目列表
- 播放节目、查看节目简介，并在正在播放页切换待播清单
- 订阅 / 取消订阅播客；节目菜单支持复制名称、链接与返回所属播客

### 播放与歌词

- 边下边播，支持标准 / 较高 / 极高 / 无损（FLAC）/ Hi-Res 音质
- 听过的歌曲缓存在本机，再次播放无需等待
- 音量均衡，暂停与继续时淡出淡入，拖动进度无杂音
- 退出后再打开，从上次的播放队列与进度继续
- 逐字歌词与翻译，正在播放页的「律动」视图与歌曲评论
- 喜欢歌曲、播放队列、随机与循环播放

### 账号与界面

- 扫码登录，登录态保存在系统凭据存储中
- 「我的歌单」与「收藏的歌单」可分别折叠，折叠后仍可新建歌单
- 主界面与正在播放页均可直接打开设置，正在播放页随窗口尺寸调整布局
- 刘海播放器：在屏幕顶部刘海处显示迷你播放器，悬停展开（在设置中开启）
- 浅色 / 深色 / 跟随系统

关注音乐人、订阅播客等账号操作需要登录。歌曲音质、VIP 歌曲与付费节目的播放能力取决于账号权限和网易云音乐服务，不绕过版权或购买限制。

## 构建

需要 Go 1.27.3+；使用 Makefile 时还需安装 `make`。

```bash
make dev     # 开发模式运行
make build   # 打包到 build/
```

也可直接使用 Go 工具命令：

```bash
go tool mygo dev
go tool mygo build
```

## 测试

```bash
go test ./internal/...  # 内部包测试，提交前运行
go test ./...          # 全部测试
```

新增或修改 UI 交互测试后，用 `go test ./internal/app -run '^TestName$' -count=5` 检查稳定性。调用网易云音乐的在线测试仅在设置 `LIVE` 时运行；生成界面截图的测试仅在设置 `NM_FRAMES` 输出目录时运行。
